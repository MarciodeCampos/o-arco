O que este curso faz diferente

Revisado a partir de uma ementa de pós-graduação de mercado, corrigindo as lacunas que ela tinha.

Evals desde cedoUm módulo inteiro sobre medir qualidade, logo após as APIs. Sem medição, não há engenharia.
Segurança de verdadePrompt injection, segurança de ferramentas e agentes, red teaming, LGPD e AI Act, com prática.
Cada tema uma vezRAG, MCP e agentes deixam de se repetir em vários módulos e ganham profundidade em um só.
A ferramenta certaTypeScript para web, APIs e agentes. Python para fine-tuning, LoRA e ML, onde o ecossistema está.
Conceitos gerais, implementação com ClaudeOs conceitos valem para qualquer provedor. A implementação principal dos labs usa Claude e o SDK da Anthropic; o Módulo 2 mostra o que muda ao trocar de provedor.
Projeto em todo móduloCada módulo termina com algo publicável, e o integrador junta tudo em um Micro-SaaS.

Escolha sua trilha

Duas trilhas resolvem os mesmos problemas, com o mesmo objetivo e a mesma forma de medir o resultado. Muda quem escreve o código. Você segue uma; a outra fica disponível em cada laboratório, como opcional.

Com código

Para quem programa ou quer aprender a programar: usa terminal, Git e uma linguagem.

O que você aprende: a construir os sistemas com as próprias mãos, em TypeScript e Python, e a medir, proteger e operar o que construiu.

  1. Preparação: rode a do Módulo 1 e o primeiro lab. Se travar, faça antes o P2
  2. Módulos 1 a 4 em ordem: são a base do resto
  3. Depois, os módulos técnicos que o seu trabalho pede, e o projeto integrador

Já constrói com LLMs? Faça os projetos que cobrem lacunas suas, mas não pule o Módulo 3: as decisões dos outros dependem dele.

Com agentes

Para quem não programa e quer construir ferramentas para o próprio trabalho.

O que você aprende: o necessário para desenvolver sem escrever código. Definir o objetivo e o que é "pronto", decidir sobre as propostas do Claude, conferir o resultado com testes e registrar por que decidiu.

  1. P1 · IA sem mistério
  2. P2 · Preparação, ou o plugin autonomo, que faz isso com você
  3. P3 · Desenvolver com agentes: o essencial desta trilha
  4. Os módulos, fazendo os laboratórios na versão com agentes. A primeira pronta é o projeto do Módulo 2; as outras estão em construção
