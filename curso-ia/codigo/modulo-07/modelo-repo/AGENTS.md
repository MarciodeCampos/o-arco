# AGENTS.md

As instruções deste repositório para agentes de código estão em [CLAUDE.md](./CLAUDE.md).

Este arquivo existe porque ferramentas diferentes procuram nomes diferentes (`AGENTS.md`, `CLAUDE.md`,
`GEMINI.md`, regras do Cursor…). Mantenha **uma** fonte de verdade e aponte as outras para ela, em vez
de manter várias cópias que divergem com o tempo.

Resumo para quem não segue links:

- Comandos: `npm test`, `npm run typecheck`, `npm run verificar` (definição de pronto).
- Dinheiro sempre em centavos inteiros (`src/dinheiro.ts`).
- Funções de cálculo puras; data recebida como parâmetro.
- Não altere testes existentes para fazê-los passar.
