# Aviso de Privacidade — Brisa

> Empresa e produtos fictícios, criados para os laboratórios do curso de Engenharia de IA Aplicada.

## Dados coletados

Coletamos dados de cadastro (nome, e-mail, telefone e endereço de entrega), dados de compra e dados de uso
dos aparelhos conectados: medições de qualidade do ar, modo de operação e horários de uso. Não coletamos
áudio nem imagens: os purificadores Brisa não têm microfone nem câmera.

## Para que usamos

Usamos os dados para entregar pedidos, prestar suporte, enviar lembretes de troca de filtro e melhorar os
produtos. Dados de uso são analisados de forma agregada e anonimizada.

## Compartilhamento

Compartilhamos dados apenas com transportadoras (para a entrega), meios de pagamento e provedores de nuvem
que hospedam o aplicativo, sempre sob contrato. Não vendemos dados pessoais.

## Seus direitos

Conforme a Lei Geral de Proteção de Dados (LGPD), você pode pedir acesso, correção, portabilidade ou
exclusão dos seus dados pelo e-mail privacidade@brisa-exemplo.com.br. Respondemos em até 15 dias.

## Retenção

Dados de qualidade do ar ficam guardados por 24 meses. Dados fiscais são mantidos pelo prazo exigido pela
legislação tributária.
