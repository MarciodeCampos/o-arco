P2.1 O terminal: o que é e como abrir

Leitura + prática · 1h

O terminal é uma janela onde você digita comandos em vez de clicar. Cada comando é uma linha: você escreve, aperta Enter, e o programa responde com texto. Os agentes de código, como o Claude Code, trabalham assim, e por isso vale entender o básico mesmo que o Claude digite a maior parte.

SistemaComo abrirPrograma que roda os comandos
Windows 10 e 11Menu Iniciar, digite Terminal (ou PowerShell)Windows PowerShell 5.1, que já vem instalado. O PowerShell 7 é uma versão mais nova, instalada à parte
MacSpotlight (Cmd + Espaço), digite Terminalzsh, parecido com o bash
LinuxCtrl + Alt + T na maioria das distribuiçõesbash

Três ideias para não se perder:

  • O terminal sempre está numa pasta. Ela aparece no começo da linha, por exemplo PS C:\Users\ana> no Windows ou ana@pc:~$ no Linux. Os comandos agem sobre essa pasta.
  • Silêncio costuma ser sucesso. Muitos comandos não escrevem nada quando dá certo. Quando dá errado, a mensagem de erro diz o quê; leia a primeira linha vermelha antes de qualquer coisa.
  • Ctrl + C interrompe o comando que está rodando. Seta para cima repete o comando anterior.

Prática

Abra o terminal e descubra em que pasta você está:

Get-Location
pwd

P2.2 Pastas, arquivos e caminhos

Leitura + prática · 1h

Um caminho é o endereço de um arquivo. No Windows ele começa pela letra do disco e usa barra invertida: C:\Users\ana\projetos. No Mac e no Linux começa pela raiz e usa barra normal: /home/ana/projetos. Nos dois, ~ é a sua pasta pessoal, . é a pasta atual e .. é a pasta de cima.

O que fazerPowerShell (Windows)bash / zsh (Mac e Linux)
Listar arquivoslsls
Listar incluindo ocultosGet-ChildItem -Forcels -la
Entrar numa pastacd projetoscd projetos
Voltar uma pastacd ..cd ..
Criar pastamkdir projetosmkdir projetos
Ver um arquivo de textoGet-Content README.md (ou cat)cat README.md
Abrir a pasta atual no gerenciador de arquivosexplorer .open . (Mac) · xdg-open . (Linux)
Arquivos que começam com ponto .env, .gitignore e a pasta .git ficam ocultos por padrão. O .env guarda segredos (chaves de API) e nunca vai para o GitHub; o .gitignore diz ao Git o que ignorar. No Windows, ative "Itens ocultos" na aba Exibir do Explorador de Arquivos.

P2.3 Instalar Git, Node e Python

Prática · 1h30

Os laboratórios usam três ferramentas: Git (histórico do código), Node.js 20+ (TypeScript) e Python 3.10+. A forma mais simples de instalar:

Windows

winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Python.Python.3.12 -e
winget install --id GitHub.cli -e

Mac

xcode-select --install     # traz o Git
brew install node python gh   # requer o Homebrew: https://brew.sh

Linux (Debian e Ubuntu)

sudo apt update
sudo apt install git nodejs npm python3 python3-venv gh

Feche e abra o terminal depois de instalar: só um terminal novo enxerga os programas recém-instalados. Depois confira as versões: 

git --version
node --version
python --version
gh --version
Python no Windows Se python abrir a Microsoft Store em vez de mostrar a versão, o atalho da Store está na frente. Use py no lugar de python (o instalador traz esse lançador), ou desative o atalho em Configurações → Aplicativos → Configurações avançadas de aplicativos → Aliases de execução. Onde o curso escreve python3, no Windows use python ou py.

No Linux, versões antigas de distribuição podem trazer um Node anterior ao 20. Confira com node --version; se for menor, siga o instalador oficial em nodejs.org.

P2.4 Git e GitHub em cinco comandos

Leitura + prática · 1h30

O Git guarda fotografias do seu projeto, chamadas commits. Com elas você vê o que mudou, volta atrás e trabalha em paralelo em branches. O GitHub guarda uma cópia na internet e é onde os agentes abrem pull requests para você revisar.

Uma vez por computador, diga ao Git quem você é e conecte o GitHub (o login abre no navegador):

git config --global user.name "Seu Nome"
git config --global user.email "voce@exemplo.com"
gh auth login --web

No dia a dia, quase tudo são estes cinco comandos (iguais no PowerShell e no bash):

ComandoO que faz
git clone <endereço>Baixa um repositório do GitHub para o seu computador
git statusMostra o que mudou desde o último commit. Na dúvida, rode este
git add <arquivo>Escolhe o que vai entrar no próximo commit
git commit -m "mensagem"Tira a fotografia, com uma frase que diz o que mudou
git pushEnvia os commits para o GitHub

Quiz rápido

Você editou dois arquivos e não lembra quais. Qual comando mostra isso sem mudar nada?

git status só lê. É o comando mais seguro para se situar antes de qualquer outro.

P2.5 PowerShell e bash: tabela de equivalências

Referência · 1h

A maior parte dos comandos do curso está escrita para bash. Nos módulos, cada bloco desses tem um botão No Windows PowerShell com a versão convertida, quando a conversão é direta. Para o resto, use esta tabela. Ela vale para o Windows PowerShell 5.1, o que vem no Windows.

No bashNo PowerShell 5.1Observação
cmd1 && cmd2Um comando por linhaO 5.1 não aceita && (o PowerShell 7 aceita). cmd1; cmd2 roda o segundo mesmo se o primeiro falhar
export CHAVE="valor"$env:CHAVE = "valor"Vale só para esta janela do terminal
source .venv/bin/activate.venv\Scripts\Activate.ps1Veja o aviso sobre scripts abaixo
python3python ou pyVeja P2.3
echo $?$LASTEXITCODECódigo de saída do último programa: 0 é sucesso
ls -laGet-ChildItem -Forcels -la dá erro no PowerShell
rm -rf pastaRemove-Item -Recurse -Force pastaApaga sem lixeira, nos dois. Confira o caminho antes
cmd | head -20cmd | Select-Object -First 20
grep texto arquivoSelect-String texto arquivo
which nodeGet-Command node
touch arquivoNew-Item arquivo
curl -s urlcurl.exe -s urlNo 5.1, curl sozinho é outro comando (Invoke-WebRequest)
Quebra de linha com \Quebra de linha com ` (crase)Ou escreva o comando numa linha só
echo "x" > arquivoSet-Content arquivo "x" -Encoding utf8No 5.1, > grava em UTF-16, que muitas ferramentas não leem
"A execução de scripts foi desabilitada neste sistema" É a mensagem mais comum no Windows, ao ativar o ambiente Python ou ao rodar npm. O Windows bloqueia scripts do PowerShell por padrão. Para liberar os scripts locais e os assinados, só para o seu usuário, rode uma vez: 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
Scripts baixados da internet sem assinatura continuam bloqueados.
Chave de API permanente $env:ANTHROPIC_API_KEY = "..." some ao fechar o terminal. setx ANTHROPIC_API_KEY "..." grava para os próximos terminais, mas em texto puro nas configurações do seu usuário. Para os labs, prefira definir na sessão ou usar um arquivo .env fora do Git.

Alternativas: o Git para Windows instala o Git Bash, onde os comandos bash do curso funcionam quase todos como estão. O WSL roda um Linux completo dentro do Windows e é a opção mais próxima do ambiente dos labs. Escolha um e mantenha: misturar os três confunde caminhos e instalações.

Quiz rápido

No PowerShell 5.1, cd projeto && npm install dá erro. O que fazer?

O 5.1 não conhece &&. Separando em duas linhas, você também vê se o primeiro comando deu certo antes do segundo.

P2.6 O primeiro projeto

Prática · 1h

Com o plugin autonomo, /autonomo:novo-projeto cria o projeto já com testes, GitHub e verificação automática. Para fazer à mão e ver cada passo: 

mkdir meu-primeiro-projeto
cd meu-primeiro-projeto
git init
Set-Content README.md "# Meu primeiro projeto" -Encoding utf8
git add README.md
git commit -m "Primeiro commit"
gh repo create meu-primeiro-projeto --private --source . --push
mkdir meu-primeiro-projeto
cd meu-primeiro-projeto
git init
echo "# Meu primeiro projeto" > README.md
git add README.md
git commit -m "Primeiro commit"
gh repo create meu-primeiro-projeto --private --source . --push

Abra o endereço que o último comando mostrar: o repositório está no seu GitHub, privado.
