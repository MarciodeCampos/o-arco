Deixe o Claude preparar tudo

Em vez de você estudar como configurar um ambiente de desenvolvimento, o Claude faz isso por você e explica cada passo. Você instala um programa, digita um comando, e ele cuida do resto: confere seu computador, instala o que falta, se dá a autonomia que você autorizar, prova que as barreiras de segurança funcionam, cria seu primeiro projeto e o coloca na internet.

Você continua no comandoO Claude pede sua aprovação antes de mudar as próprias permissões, antes de gastar dinheiro e antes de publicar em produção. Suas senhas e chaves ficam fora do alcance dele.

1 · Instalar o Claude Code

Você precisa de uma conta Claude com acesso ao Claude Code (ver planos). Abra o terminal do seu computador:

  • Mac: abra o app Terminal (procure "Terminal" no Spotlight, com ⌘ + espaço).
  • Windows: abra o PowerShell (menu Iniciar, digite "PowerShell").
  • Linux: abra o terminal da sua distribuição (Ctrl + Alt + T no Ubuntu).

Copie e cole o comando do seu sistema e aperte Enter:

Mac, Linux ou WSL

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell)

irm https://claude.ai/install.ps1 | iex

Depois, digite claude e aperte Enter. Na primeira vez, ele abre o navegador para você entrar na sua conta. Se algo der errado, o guia oficial de instalação tem as alternativas (Homebrew, WinGet) e as soluções para erros comuns.

2 · Instalar o plugin autonomo

Com o Claude Code aberto, digite estes dois comandos, um de cada vez:

/plugin marketplace add MarciodeCampos/o-arco
/plugin install autonomo@o-arco

O segundo abre um painel com os detalhes do plugin: confirme a instalação. Depois digite /reload-plugins para ativar.

Prefere instalar pelo terminal, fora do Claude Code? 
claude plugin marketplace add MarciodeCampos/o-arco
claude plugin install autonomo@o-arco

Depois abra o Claude Code com claude.

3 · Pedir para começar

No Claude Code, digite:

/autonomo:comecar

Ou, se você já usou o Claude Code pelo menos uma vez neste computador, clique: Abrir o Claude Code e começar. O link só preenche o comando; nada acontece até você apertar Enter.

Também funciona pedir com suas palavras: "quero preparar meu computador para criar um site".

Segurança, com testes

O nível recomendado liga o modo auto, em que um segundo modelo revisa cada ação, e acrescenta barreiras fixas. Cada linha abaixo foi testada no Claude Code 2.1.316, inclusive no modo que pula todas as checagens, com um arquivo de segredo falso:

TentativaSem barreirasCom o plugin
Ler o arquivo .env com a ferramenta de leituraLê o segredoBloqueado
Ler .env com cat, grep -r ou um script PythonLê o segredoBloqueado (com sandbox ativo)
Ler uma chave em ~/.ssh por um scriptLêBloqueado (com sandbox ativo)
git push --force, escrito de cinco formas diferentesExecutaBloqueado
Apagar um repositório do GitHubExecutaBloqueado
Criar arquivo fora da pasta do projetoCriaBloqueado pelo sandbox
Criar arquivos, rodar código, fazer commit e push normalFuncionaFunciona

Depois de configurar, o próprio Claude repete esses testes no seu computador (/autonomo:verificar-barreiras) e mostra o resultado.

Limites que você deve conhecer
  • No Linux, o sandbox precisa de dois programas (bubblewrap e socat). Sem eles, o Claude Code roda sem sandbox, em silêncio. O plugin confere e instala.
  • Regras de texto podem ser contornadas escrevendo um comando de um jeito incomum. Por isso há três camadas: regras, o classificador do modo auto e, nos seus projetos do GitHub, a proteção da branch principal.
  • Ler também tem risco. Tudo o que o Claude lê (um arquivo baixado, uma página, um log) entra no contexto dele, e pode conter instruções escritas por outra pessoa para enganá-lo. As barreiras limitam o que ele consegue fazer depois, mas não impedem que ele leia algo malicioso.
  • O modo "autonomia total, sem nenhuma checagem" só é configurado dentro de um contêiner ou na nuvem, nunca direto no seu computador.

Sem instalar nada no computador

Em claude.ai/code o Claude Code roda num contêiner na nuvem, ligado a um repositório do seu GitHub, e continua trabalhando com o computador desligado. É o ambiente isolado em que a autonomia total faz sentido. Você acompanha pelo navegador ou pelo app do celular.

Perguntas frequentes

Quanto custa?

O plugin é gratuito. O uso do Claude depende do seu plano; dentro do Claude Code, /usage mostra o consumo. Plataformas de publicação têm planos gratuitos; o Claude avisa antes de qualquer coisa que possa gerar cobrança.

Posso desfazer?

Sim. O Claude faz backup das configurações antes de mudar e explica como restaurar. Para remover o plugin: claude plugin uninstall autonomo@o-arco.

Funciona no Windows?

Sim, com uma ressalva: o sandbox não existe no Windows nativo. As regras de proteção funcionam; para a proteção completa, o Claude recomenda o WSL ou um contêiner.

O Claude vê minhas senhas?

Ele nunca pede senhas na conversa. Logins acontecem no navegador, senhas do computador são digitadas por você no terminal, e chaves de serviços vão para arquivos e painéis que o Claude é configurado para não ler. As barreiras foram testadas nos casos da tabela acima e têm os limites descritos ali.
