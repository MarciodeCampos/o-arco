Antes de começar

O Claude que você conhece e o Claude no seu computador

Se você só usou o Claude pelo app ou pelo site, ele trabalhava em computadores da Anthropic. O Claude Code no terminal trabalha no seu computador.

App e site (claude.ai)

  • Conversa, escreve e analisa o que você envia.
  • Roda na nuvem: não enxerga seus arquivos nem instala programas no seu computador.
  • O Claude Code na web (claude.ai/code) também roda na nuvem, ligado a um repositório do GitHub.

Terminal (Claude Code no seu computador)

  • Lê e cria arquivos dentro da pasta que você abrir.
  • Instala programas, roda testes, publica sites.
  • Usa a mesma conta e o mesmo plano do app.
  • Pede sua aprovação antes de mudanças importantes.
Por que o terminal? Para o Claude preparar o seu computador, ele precisa estar nele. É isso que o plugin autonomo faz, com barreiras de segurança testadas.

Passo 1 de 9

Abra o terminal

  1. Clique no menu Iniciar (ou aperte a tecla ⊞ Win).
  2. Digite PowerShell.
  3. Clique em Windows PowerShell.
Não precisa abrir como administrador. Se o Windows abrir o app Terminal, tudo bem: é o mesmo PowerShell, numa janela com abas.
  1. Aperte ⌘ + espaço para abrir o Spotlight.
  2. Digite Terminal.
  3. Aperte Enter.
  1. Aperte Ctrl + Alt + T (Ubuntu e a maioria das distribuições).
  2. Ou procure Terminal no menu de aplicativos.

Como o terminal funciona

Você digita um comando e aperta Enter. Ele responde com texto. Quando aparece de novo a linha que termina em >%$, ele está pronto para o próximo comando.

Para colar: Ctrl + V ou clique com o botão direito.⌘ + V.Ctrl + Shift + V.

Passo 2 de 9

Instale o Claude Code

Copie o comando, cole no terminal e aperte Enter. Ele baixa e instala o programa oficial da Anthropic.

PowerShellirm https://claude.ai/install.ps1 | iex
Terminalcurl -fsSL https://claude.ai/install.sh | bash
  1. Espere até aparecer a mensagem de instalação concluída (successfully installed).
  2. Feche o terminal e abra de novo. Assim ele passa a reconhecer o comando claude.
  3. Para conferir, digite claude --version. Deve aparecer um número de versão.
Apareceu "claude não é reconhecido" ou "command not found"? Feche e abra o terminal. Se continuar, o final da instalação mostra um comando para acrescentar o Claude ao PATH (a lista de lugares onde o terminal procura programas): copie e rode esse comando. O guia oficial tem as outras soluções.
Passo 3 de 9

Crie uma pasta para o projeto

O Claude trabalha dentro da pasta em que você o abrir. Crie uma e entre nela, com um comando de cada vez:

1ºmkdir ~/meu-primeiro-projeto
2ºcd ~/meu-primeiro-projeto
mkdir
"make directory": cria a pasta.
cd
"change directory": entra na pasta.
~
a sua pasta pessoal (C:\Users\seu-nome) (/Users/seu-nome) (/home/seu-nome).

Depois do cd, a linha do terminal passa a mostrar meu-primeiro-projeto. É assim que você sabe que está dentro dela.

Windows PowerShell 5.1
PS C:\Users\voce> mkdir ~/meu-primeiro-projeto && cd ~/meu-primeiro-projeto O token '&&' não é um separador de instruções válido nesta versão.
Por que um de cada vez? O PowerShell que vem no Windows (versão 5.1) não aceita && para juntar dois comandos. Se aparecer esse erro vermelho, nada quebrou: rode os dois separadamente.
Terminal
~ $ mkdir ~/meu-primeiro-projeto ~ $ cd ~/meu-primeiro-projeto ~/meu-primeiro-projeto $

Passo 6 de 9

Entre na sua conta

  1. Quando ele perguntar o tipo de conta, escolha Claude account with subscription (a conta do seu plano, a mesma do app).
  2. O navegador abre na página do Claude. Entre na conta, se pedir, e clique em Autorizar.
  3. Volte ao terminal. Deve aparecer Login successful. Aperte Enter.
O navegador não abriu? O terminal mostra um endereço. Copie, cole no navegador e faça o login. Se a página mostrar um código, copie o código e cole no terminal, onde ele pede Paste code here.

Você nunca digita sua senha no terminal: o login acontece no navegador.

Passo 7 de 9

Autorize a pasta

O Claude pergunta se você confia nos arquivos desta pasta. Como foi você quem acabou de criá-la, escolha Yes e aperte Enter.

Regra para o futuro: só confirme em pastas suas ou de fontes em que você confia. Arquivos de terceiros podem trazer instruções escondidas para enganar o Claude.

Pronto: o Claude Code está aberto. A caixa embaixo, com o sinal >, é onde você escreve, em português mesmo.

claude
Do you trust the files in this folder? C:\Users\voce\meu-primeiro-projeto Claude Code may read, write, or execute files contained in this directory. ❯ 1. Yes, proceed 2. No, exit

O texto exato pode variar um pouco conforme a versão.

Passo 8 de 9

Deixe o Claude Code atualizado

O plugin usa recursos recentes. Antes de instalá-lo, confira se você tem a versão mais nova.

  1. Saia do Claude Code digitando /exit (ou aperte Ctrl + C duas vezes).
  2. No terminal, rode:
    claude update
  3. Abra de novo, ainda dentro da pasta:
    claude
terminal
meu-primeiro-projeto> claude update Current version: 2.1.143 Checking for updates... Successfully updated to version 2.1.316 meu-primeiro-projeto> claude

Os números de versão são um exemplo. O Claude Code também se atualiza sozinho com o tempo.

Passo 9 de 9

Instale o plugin autonomo

Agora dentro do Claude Code (na caixa com >), digite um comando de cada vez:

1º · catálogo/plugin marketplace add MarciodeCampos/o-arco
2º · plugin/plugin install autonomo@o-arco
3º · ativar/reload-plugins
marketplace add
adiciona o catálogo de plugins do curso, que fica no GitHub.
install
instala o plugin. Abre um painel com os detalhes: confirme.
reload-plugins
ativa o plugin sem precisar fechar o Claude.
Apareceu "Unknown command"? O Claude Code está desatualizado. Volte ao slide anterior e rode claude update.

O plugin fica instalado no computador todo. Nos próximos projetos, você não precisa repetir este passo.

A partir daqui, o Claude conduz

Digite e comece

/autonomo:comecar

Ou peça com suas palavras: "quero preparar meu computador para criar um site".

  1. ObjetivoPergunta o que você quer construir e quanta experiência tem.
  2. DiagnósticoConfere o computador, sem mudar nada.
  3. InstalaçãoInstala o que falta e conecta o GitHub pelo navegador.
  4. AutonomiaConfigura o que pode fazer sozinho e prova que as barreiras funcionam.
  5. Primeiro projetoCria o projeto com testes, GitHub e verificação automática.
Você continua no comando. O Claude pede aprovação antes de mudar as próprias permissões, antes de gastar dinheiro e antes de publicar na internet. Uma tela de aprovação vai aparecer quando ele for mudar as configurações: ele avisa antes.
Problemas comuns

Se algo der errado

Erro vermelho com &&

É o PowerShell 5.1 do Windows. Rode os comandos um de cada vez.

"claude não é reconhecido"

Feche e abra o terminal. Se continuar, rode o comando de PATH que a instalação mostrou.

O navegador não abriu no login

Copie o endereço que o terminal mostra e cole no navegador. Se a página der um código, cole no terminal.

"Unknown command: /plugin"

Saia com /exit, rode claude update e abra de novo.

Fechei o terminal. E agora?

Abra o terminal, entre na pasta com cd ~/meu-primeiro-projeto e digite claude. Tudo continua instalado.

Travou ou não entendi

Pergunte ao próprio Claude, em português: "o que aconteceu?" ou "explique o que você está fazendo".
